The record behind
the recording.

Signed snapshots preserve an exact sequence of bytes under storage-provider retention. They do not prove copyright ownership, an original DAW session or an independently witnessed creation time.

Owner workspace

i
Archival verification, separate from upload.

A retained snapshot preserves exact bytes until a stated date using configured archival storage and signing. If unavailable, no retained stamp is confirmed. A song ID cannot activate storage, and uploading again will not enable it. Byte observations are a separate check, not a retained copy or proof of ownership.

Sign in through the catalog. Capture is limited to the active sale master. Uploads automatically attempt capture only when retained storage and signing are enabled.

This identifies your catalog song. Use it with the master version ID to capture or list snapshots. To inspect one signed snapshot, use its snapshot record ID instead. Neither ID is a signing key.

Parent relationships are creator-declared, not proof that a remix was derived from that source. Existing snapshot lineage cannot be rewritten through a retry.
