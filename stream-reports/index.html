Where to find these files
  • DistroKid: in Bank, open the detailed earnings report and download it as TSV.
  • TuneCore, CD Baby, Amuse, Ditto and others: download the sales or royalty report as CSV.
  • Spotify for Artists and Apple Music for Artists: open your songs list, choose the date range, and export it as CSV. Pick the month above if the file has no date column.

PDF statements and Excel files can't be read; save them as CSV first. The same file is never counted twice.
